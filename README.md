# 经济与购买系统

## 项目描述

经济与购买系统的bug修复项目。核心模块 `game/economy_system.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 奖励计算不考虑击杀助攻拆弹等行为
- 购买菜单价格写死无冷却不检查经济
- 经济重置完全没做玩家带着上局的钱
- 击杀奖励写死不考虑武器类型连杀对方经济
- 团队经济完全没做不能给队友买武器
